## Project Overview

This conversation documents the complete development of an Old School RuneScape (OSRS) Skilling Assistant web application. The project evolved from a basic React app with tabs to a comprehensive inventory management system with a full-stack architecture including Express backend, SQLite database, and advanced UI features.

## API Endpoints

### Seed Management
- `GET /api/seeds` - Retrieve all seeds
- `GET /api/seeds/:id` - Get specific seed by ID
- `POST /api/seeds` - Create new seed
- `PUT /api/seeds/:id` - Full update of seed
- `PATCH /api/seeds/:id` - Partial update of seed
- `DELETE /api/seeds/:id` - Delete seed
- `POST /api/seeds/reset` - Reset to initial data (dev only)

### System
- `GET /api/health` - Health check endpoint
